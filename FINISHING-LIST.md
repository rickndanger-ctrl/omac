# Omac finishing order

## Core first
- Reliable app shelf: one remembered window per supported app, recall on current page, tuck on page changes, preserve native sizing and sessions.
- Consistent dark Omac menu, app selector, and shortcut guide.
- Installed apps accessible inside Omac, without opening the Applications folder.
- Customizable favorite-app shortcuts; guide reflects actual bindings.
- Window focus recovery and optional left/right placement.
- Keyboard switching between Mini 1 and Mini 2, with reliable shortcut handoff.
- Verify both Macs and preserve rollback before calling the core ready.

## Final pass, explicitly deferred
- Finder shelf integration. Keep Command–Option–E as a normal Finder launcher meanwhile.
- Optional Animated Background menu switch, off by default; static wallpaper remains default.
- Screensaver / dismissible idle animation and visual polish.
- App-specific completion badges, only where a reliable signal exists.
- Agent-terminal launch presets.
- Installer packaging, permission walkthrough, and tester release after core validation.

No paid media generation or publication is authorized by this list.
