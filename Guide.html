Five-page Control Center

Each page starts empty. Open terminals and desktop apps there; switching pages keeps them running. Desktop apps retain their own minimum window sizes. Existing app shortcuts may return to the page containing that app; use its New Window command for another window.

Use the ▦ menu to open four or six plain Ghostty terminal windows. Start your own agents in any terminal. No agents, browser, or desktop apps are launched automatically.

Press Escape to dismiss this window. Command stands in for Omarchy's Super key.

Command stands in for Omarchy's Super key. Directional focus, swapping, terminal launch, and fullscreen follow its conventions. Resizing is adapted to AeroSpace. Four terminals use two columns; six use three. Reopening reuses matching terminal windows; selecting four never closes existing fifth or sixth sessions.

These shortcuts override the focused application's usual shortcuts while active. Pause or Exit releases them. Resume from the menu. Normal trackpad use remains available.

Exit leaves terminal sessions running. Closing a terminal can stop its foreground agent. Window restoration is best effort. No login startup is installed.

Omarchy shortcut reference

New Control Center terminals use 85% opacity and a subtle blur. Existing terminal instances retain their appearance until closed and reopened. Native macOS fullscreen disables transparency.
