# Omac appearance

The selected direction is the user's supplied dark-glass wallpaper with a green pixel-cut OMAC wordmark and Apple silhouette. This is a personal customization, not an Apple or Omarchy product.

- `wallpapers/omac-obsidian.png`: supplied Green Glass original.
- `wallpapers/omac-pine.png`: Silver Glass variation (the internal filename preserves the existing selection key).
- `wallpapers/omac-amber.png`: Amber Glass variation.
- `wallpapers/archive/`: earlier directions retained, not installed as the default.
- `screensaver/`: native Swift ScreenSaverView implementation and preview app.

Silver and Amber were edited with the built-in image-generation tool, using the supplied Green Glass wallpaper as reference. Prompt: preserve the exact composition, pixel-cut OMAC lettering, dark glass Apple silhouette and foreground; change only green lettering, rim lighting, reflections and accents to soft silver-white pearl / restrained warm amber-champagne. Keep dark charcoal, no extra text or UI. Images are 1672×941; no 4K-resolution claim is made.

Omac Appearance in the menu bar selects a wallpaper. Enter applies it to connected displays; Exit restores saved original image URLs. Live/dynamic wallpaper playback and original scaling options are not captured by the image URL backup.
