Questions

Is the free version really the full app?

Yes. Tiling, pages, Omac Terminal, Jev and every built-in theme. Paid versions add updates, plugins and creation tools.

What can I change as a Creator?

Wallpapers, themes, and your own plugins. Omac's core functions and logo stay the same so it always works the way you expect.

Does Jev need an API key?

Jev uses a key you add once in Settings. Simple window moves work offline.

Can I cancel the monthly plan?

Any time. You keep the app and everything you made.
