Up and running
in five minutes.

Install, grant one permission, and start working. Press ⌘ K any time to see every shortcut.

Install

Open the download and drag Omac to Applications, then open it.

Allow Accessibility

macOS asks once. Turn Omac on in System Settings → Privacy & Security → Accessibility. This is how Omac moves windows.

Open a terminal

Press ⌘ ↩. It tiles itself and is ready to type.

Bring your apps

Press ⌃ ⌥ ↩, type an app name, and it opens already in place.

Meet Jev

Type jev "bring chrome next to me", or turn on voice in Settings and just say it.

First launch

If nothing moves, it's one switch.

Omac needs Accessibility to arrange windows. If windows don't tile after Setup, open System Settings → Privacy & Security → Accessibility, turn OMAC on (or off and on again), then press ⌘ ↩. Omac tells you on screen if anything else is missing.

Two Macs?

Choose "two Macs" in Setup on both, then OMAC menu → Pair with other Mac… on each and confirm the matching code. Use ⌃ ⌥ 1 / 2 to switch.

Where are the terminal commands?

OMAC menu → Settings → Install omac command. Then try omac doctor and jev "bring chrome next to me".

The keys worth knowing.

Everything else is in the Shortcut Guide.

  • ⌘ ↩New terminal
  • ⌘ ←↑↓→Move focus between tiles
  • ⌘ WClose; focus goes to the tile beside it
