For creators

Make a theme in a minute.

A theme is one small file. Colors, a wallpaper texture, and a terminal palette. The Omac logo and core functions stay locked, so nothing ever breaks.

Download Omac
my-theme.json
{
  "name": "Midnight Oak",
  "texture": "wood",
  "gradient": { "top": "#3B2A1E", "bottom": "#1A120C" },
  "accent": "#D2B48C",
  "terminal": { "background": "#16110D" },
  "light": false
}
